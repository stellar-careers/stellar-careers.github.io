Low Codeとは？
事業内容・働き方・キャリアを解説【2026年版】

Low Codeは、Microsoft 365の環境で使える生成AIとローコードツールを、企業の現場に定着させる支援を専門とする会社です。2022年2月の設立で、本社は東京都品川区です。システム開発やライセンス販売は行わず、研修からハッカソン、社内コミュニティの運営までを通じて、社員が自らツールを使いこなす状態をつくります。本記事では、事業内容と働き方、キャリアの広げ方を解説します。

会社概要

社名株式会社Low Code
設立2022年2月
代表者代表取締役 CEO 文山泰汎
本社東京都品川区西五反田7丁目1番10号6F
事業内容Microsoft製品の生成AI・ローコードツールの定着化支援
主なサービスLow Code In-house／Generative AI In-house／AI Agents In-house

CEOの文山泰汎氏は、リンクアンドモチベーションでIT企画と戦略立案に携わったのち、日本マイクロソフトに移りました。クラウド＆AIソリューション本部のテクニカルスペシャリストとして、自動車や金融、不動産業界の大手企業に技術支援を行ってきた経歴を持ちます。

同社の経営をCEOとともに担うのが、COOの青木晃一氏です。教育系スタートアップでセールスとマーケティング全般を担ったのち、AIスタートアップで生成AIを使った社内の業務効率化プロジェクトを推進しました。

事業内容と特徴

Low Codeの事業は、Microsoft 365に備わる生成AIとローコードツールを、顧客企業の現場に定着させる支援です。サービスはLow Code In-house、Generative AI In-house、AI Agents In-houseの3つにまたがります。主な顧客は、Microsoft製品を導入している大手企業です。

このうちLow Code In-houseは、Power Platformを使い、社員が自ら業務の自動化やアプリ開発に取り組める体制をつくります。Generative AI In-houseは生成AIのCopilotの導入と定着を支えるサービスで、2024年4月に提供を始めました。AI Agents In-houseでは、Copilot StudioやCopilot agentsを使って、部署ごとに合ったAIエージェントの開発と導入を支援します。

同社のもうひとつの特徴は、事業の範囲を定着化に絞っていることです。システム開発やライセンス販売は行いません。上流の提案で終わらせず、現場の社員が使い方を身につけ、日々の業務に組み込むところまでを担います。

この定着を進める手段が、研修とハッカソン、社内コミュニティの組み合わせです。進め方の土台は、定着化のフレームワークであるADKARです。関心づくり・動機づけ・知識の習得・実践・定着化という段階に沿って、顧客ごとに支援を組み立てます。たとえば関心づくりの段階では社内報での発信を、実践の段階ではハッカソンを、定着化の段階ではユーザーコミュニティの運営を行います。

こうした支援の特長は、Microsoft 365に標準で備わるCopilotやPower Appsを使うことです。新たなツールの導入費用をかけずに、顧客は社内での内製化を進められます。伴走を担うのは、元日本マイクロソフト社員を中心としたチームです。研修にとどまらず、PMOとしてプロジェクトの推進を支える支援にも対応します。

実際に、ある電力会社グループの海外事業会社では、まずMicrosoft 365の活用研修で足場を固めました。そのうえで意欲のある社員向けにPower Appsの開発研修へ進み、翌年のハッカソンでは社内用語の検索アプリや領収書の精算申請アプリが生まれています。

成長性・外部評価

Low Codeは2025年12月、みずほ銀行と地方銀行からの融資により、総額4億円の資金を調達しました。調達の目的は、人材の採用と育成、社内のAIオペレーションの構築への投資です。

背景には、定着化に特化してきたこれまでの実績があります。支援先では、週単位で90%近くの社員が生成AIに触れる状態も生まれました。

実際に、あるITサービス企業の支援では、全社員のCopilot利用率が2025年1月の16%から同年10月には34%へ伸びました。Low Codeの講師によるエージェント研修を経て、社員が作成したAIエージェントも同年8月の52件から10月には154件へ増えています。

さらに、支援で得た知見を外部にも公開しています。2024年10月には、Microsoft 365 Copilotの活用ノウハウをまとめた計140ページのガイドブックを2冊、無料で公開しました。その後もCopilot Studioのガイドブックや、導入時のセキュリティガバナンスをまとめた資料を出しています。

働き方・カルチャー

Low Codeの働き方は、原則出社です。社内のコミュニケーションを促し、生産性を高めるための方針で、体調不良や悪天候のときはリモート勤務もできます。

この方針の背景には、組織の広がり方があります。毎月の入社者が多いため、会社のことや技術的な疑問を社内で気軽に解消できる環境を整えています。毎朝の朝会もそのひとつで、会社全体の情報を共有し、相談事項をその場で解決する場です。

その組織を形づくるメンバーの背景は多様です。大手IT企業やWeb系ベンチャー、人事コンサルティングの出身者が集まり、技術とビジネスの両面から事業を広げています。

こうした組織の軸には、「常に楽しもう」「“意味のあること”をちゃんとやろう」「プロとして自ら生成AI/ローコードを使いこなそう」という3つのバリューがあります。

このうち3つ目のバリューは、社内の運営にも表れています。社内にはAI活用を進めるAI推進室があり、AIツールの全社展開を進めてきました。福利厚生にも、生成AIツールの利用料を会社が負担する制度があります。自社で試して得た知見は、顧客への支援に還元します。

キャリアパス・育成

Low Codeのコンサルタントのキャリアは、定着化の現場から始まります。入社後はまず研修の運営やハッカソンの実施を担当し、段階を追って企画業務やプロジェクトマネジメントを任されます。

その先のプロジェクトでは、構想・企画から推進と実行、定着と効果検証までを一貫して担います。役割やフェーズごとの分業を置いていないため、提案した施策を自らの判断で形にできます。

一方、営業職が向き合うのは、大手企業の経営層や経営企画部、DX推進部です。課題のヒアリングから施策の提案、契約の締結までを一気通貫で受け持ち、営業戦略やマーケティング施策の立案にも携わります。

また、顧客の支援にとどまらない役割もあります。自社の新サービス開発や採用活動、組織づくりにも関われるため、事業と組織の両方をつくる経験を積めます。

こうした働きは、年2回の評価と昇級に反映されます。評価は年齢や入社年次に関係なく、成果と行動の両面で行います。行動の評価で見るのは、バリューの体現や組織への貢献といった定性面です。

加えて、学びの場も社内に用意しています。ローコードと生成AIの社内ナレッジを共有する技術インプット会を定期的に開き、メンバー同士で知見を深めています。

向いている人

AIの導入で終わらせず、現場で使われるところまで見届けたい人に向いています。同社の仕事は、ツールが入った後の現場に伴走し、社員の行動の変化と定着を追うことです。研修で使い方を伝え、ハッカソンで業務に当てはめ、コミュニティで活用を続けてもらうまでを受け持ちます。

また、顧客の課題に寄り添って提案や伴走をしてきた経験を生かしたい人にも合います。コンサルティング営業やSaaSのカスタマーサクセス、業務改善のプロジェクトで培った経験は、定着化の支援と重なる部分が大きいといえます。

さらに、組織が広がる時期に、事業と会社づくりの両方に関わりたい人にも向いています。フェーズごとの分業を置かない進め方のもとで、自社の新サービス開発や採用活動にも携われます。

加えて、新しい生成AIに自分から触れ続けたい人にも合う環境です。社内でAIツールを全社に展開し、自ら使いこなした経験を顧客の支援に生かしています。

まとめ

Low Codeは、Microsoft 365の生成AIとローコードツールを、企業の現場に定着させる支援を専門とする会社です。研修とハッカソン、社内コミュニティを組み合わせ、定着化のフレームワークに沿って社員が自らツールを使いこなす状態をつくります。2025年12月には、採用・育成と社内のAIオペレーション構築を目的に、総額4億円を調達しました。ステラキャリアズでは、各社の選考傾向を踏まえたご相談を承っています。

※本記事は2026年8月時点で作成しています。制度・人員規模・案件構成などは変更される場合がありますので、最新の情報は公式サイト等をご確認ください。
