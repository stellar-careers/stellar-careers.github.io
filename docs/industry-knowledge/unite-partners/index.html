Unite Partners（ユナイトパートナーズ）とは？
事業内容・働き方・選考の傾向を解説【2026年版】

Unite Partners株式会社は、創業5年目の独立系総合コンサルティングファームです。製造業を中心に、戦略立案から業務改善、DX推進までを手がけます。全案件を大手企業との直接取引で受注し、下請け構造を挟みません。正社員30名で東京と大阪に拠点を持ち、創業から4年で顧客数100社、経験プロジェクト1,000件を超えました。本記事では、事業内容・組織・働き方・選考の傾向を整理します。

会社概要

社名Unite Partners株式会社
創業創業5年目（2026年6月時点）
代表者代表取締役 小林大輝
正社員数30名
拠点東京・大阪の2拠点
直接取引社数100社以上（うち80%がプライム上場企業）
経験プロジェクト数1,000件以上
月商1億円

代表の小林大輝氏は東京大学を卒業後、デロイトトーマツコンサルティングに入社し、製造業全般（特に自動車業界）と物流業界を主な顧客として戦略から実行までを担いました。その後独立・起業し、2度の事業売却を経てUnite Partnersを創業しています。

その創業の背景には、恩師である瀧本哲史氏の影響があります。小林氏が学生時代に立ち上げたゼミで出会った瀧本氏は、自らの武器を持って世界を変えることを説き続けました。大手ファームで感じた現実との落差が起業の動機になり、規模と品質を両立して完遂まで顧客と走り切れる組織をつくるという方針が、いまの事業設計に表れています。

事業内容と特徴

Unite Partnersの案件は、すべて大手企業との直接取引です。下請け構造を挟まないため、提案できる裁量の幅が変わります。継続取引が80%、顧客のうち上場企業が80%という構成です。支援先はメーカー、物流、エンタメ、建設に広がります。エネルギー、化学、製薬、IT、商社にも及びます。

そのサービスは3本を組み合わせて動きます。「プロサポ」は数十万円/月から始められるチケット制のコンサルティングで、支援内容を絞ることで小さく着手できます。予算に合わせてチケットを購入し、使った分だけ消費する会計です。対応する人材の職歴と専門性を事前に確認し、面談してから選べます。

このうち2本目の「うごラボ」は、コンサルタントと社内エンジニアがワンチームで動きます。AI導入領域の選定からアプリの開発・運用までを一貫して担い、提言がPowerPointで終わる構造を避けています。3本目が経営の高度化と意思決定支援の領域です。小さく着手した案件を大規模・長期の支援へ育てる流れをつくっており、この仕組みがあるため大手ファームが入れなかった国内時価総額トップクラスの素材メーカーにも入っています。

その価値提供を支えるのが、少数精鋭・AI・現場主義の3つです。少数精鋭のコンサルタントを、営業専任チーム、社長直下のAI開発チーム、数千人規模の外部専門家ネットワークが支えます。コンサルタントが顧客との関係構築や案件獲得に時間を割かず、プロジェクトに集中できる分業です。

このAI開発チームは、社内の営業・バックオフィス向けのミニアプリを開発しています。初回商談のセールスシナリオを考案するbotや、支店名と顧客名の入力だけで営業資料を自動作成するアプリを短期間で作りました。その知見を「うごラボ」として顧客向けに展開しています。

一方、現場主義のほうは、戦略策定フェーズや高難度案件を専門チームで対応する形です。実行フェーズでは人材が常駐して現場の課題や要望を吸い上げながら動きます。

その案件には、戦略とシステムの両方があります。戦略側では、大手機械メーカーの事業DX推進に向けた組織デザインと採用グランドデザインの構築を手がけました。大手化学メーカーにおける特定事業の投資判断・撤退シナリオ策定、大手エンタメ企業の次世代成長戦略と中期経営計画の策定、医薬品メーカーの内部統制の現状分析もあります。システム側では、大手電力会社の生成AI全社導入を通じた業務プロセス変革とリスキリング支援、食品メーカーの基幹システム刷新支援を担いました。大手小売企業のグランドデザイン策定、ゼネコン大手の事業プロセス効率化支援も進めています。

このほか大阪拠点は、関西に拠点のある企業を現地で完結して支援するために設立されました。所在地は大阪市中央区平野町です。遠隔支援では把握しにくい現場の課題を近距離で拾い、実行フェーズまで組織の内部に入り込むという狙いです。

成長性・外部評価

Unite Partnersは創業から4年で、顧客数100社以上、経験プロジェクト1,000件以上に達しました。年平均成長率は400%を超え、月商は1億円規模です。代表の過去の人脈に頼らず、独立後にゼロから開拓した顧客で構成されている点が、この成長の性格を示します。

その案件獲得は営業分業型です。コンサルタントとは別に案件獲得専門のセールス部隊があり、新規開拓を担います。この設計により、シニアマネージャーやプリンシパルは新規商談よりもデリバリーに時間を使えます。

働き方・カルチャー

Unite Partnersの働き方は、完全フレックスタイム制度です。勤務は原則出社ですが、採用ポジションによってリモート勤務を認める場合があります。実際の運用は職位で分かれ、シニアコンサルタント以上は週2日出社・週3日在宅、コンサルタント以下は週4日出社（入社直後は週5日）が目安です。顧客先に常駐するケースもあります。マネージャー以上は育児・介護の事情に応じて在宅が優遇されます。

また、完全週休二日制で、年末年始休暇、慶弔休暇、サバティカル休暇があります。社会保険は完備で、書籍購入費は全額補助されます。

そのカルチャーは「狂気と叡智」という言葉で表されています。常識を疑って不可能に見えるテーマに手を挙げる胆力と、業界や商売の理を理解したうえで賢く戦う姿勢の両輪という考え方です。大手ファームがひしめく市場に最後発から挑み、SaaSの発想やテレアポ、プロサポといった業界の慣行にない手段を持ち込んできた経緯が、この言葉に対応します。

この言葉のとおり、成長意欲のある人にはフルコミットで支援します。主体的に学ぶ姿勢とコーチアビリティを重視する組織です。

このほか社内の場としては、四半期に一度の「UP World」があります。コンサルタント・営業・バックオフィスが部署や役職の垣根を越えて会社の今後を議論し、終了後に懇親会があります。年末の「Year End Party」は、協業パートナーのコンサルタントも招く年次の催しです。ウーパールーパーをモデルにしたマスコットキャラクターもいます。

キャリアパス・育成

Unite Partnersの育成体制は、新卒採用の開始とともに整えられました。2025年に新卒1期生が入社し、基礎スキルを教える3日から1か月の研修が用意されています。研修の出発点はPowerPoint作成や議事録作成、AIの基礎スキルです。イシュードリブン、ロジカルプレゼンテーション、問題解決、ワークプランニング、プロジェクトマネジメントまで含みます。マネージャー向けの研修もあります。

そのオンボーディングは3日から2週間のプログラムです。カルチャーと社内ルールのインプット、メンター制度、ジュニアメンバー向けの研修が組まれています。アサインは個人の希望と成長ニーズに合わせ、その後も週次の1on1で課題を相談できます。

この案件の割り振りにも方針があります。若手は原則1〜2プロジェクトに集中し、まず強みが活きる領域を主軸にして早く成果を出せる状態をつくります。案件のバランスは強みが活きる領域が60〜80%、新たな挑戦が20〜40%という目安です。本人の志向と能力を踏まえて挑戦枠を徐々に増やし、数をこなすより深く没頭させます。

さらに、組織づくりへの関与機会もあります。マネージャーとコンサルタントには「大臣制度」があり、社内の特定領域の意思決定権を持って組織づくりに関わります。プリンシパル以上に任されるのは、社内ルールや仕組みづくりです。挙手でやりたい領域に挑める運用です。

こうした環境に集まっているのは、大手ファーム出身者です。在籍者の8割を占め、デロイト、EY、アクセンチュア、IGPIの出身者が在籍します。

中途選考の傾向

Unite Partnersの中途選考は、カジュアル面談（30分） → 面接2回（各60分） → 内定という流れです。カジュアル面談は代表が担当し、会社説明と候補者の質問への回答に充てられます。その後の2回の面接でスキルとカルチャーフィットを確認します。

その選考は対話中心のプロセスで、経験よりもポテンシャルとカルチャーフィットが重視されます。

向いている人

大手ファームで案件の規模や採算の都合に違和感を持ってきた人に向いています。依頼があってもプロジェクト化できないという状況の反対側にあるのが、プロサポという小さく始める仕組みです。実際にこの仕組みで、大手ファームが入れなかった企業にも入っています。

また、戦略とシステムの両方に関わりたい人にも合います。案件は戦略側とシステム側の両方があり、ITやPMOの案件だけでなく戦略案件も担えるため、コンサルタントとしての幅を広げられます。強みが活きる領域を60〜80%、新たな挑戦を20〜40%とする配分が、無理なく幅を広げるための目安です。

さらに、提言で終わらせたくない人にも向いています。実行フェーズでは常駐して現場の課題を拾い、うごラボではエンジニアと組んでアプリの開発・運用まで担います。PowerPointを納品して離れる関わり方にはなりません。

このほか、組織づくりに関与したい人にも合います。正社員30名で創業5年目という規模のため、社内の特定領域の意思決定を担えるのが大臣制度です。上の層が詰まっていないので、挙手でやりたい領域に挑める余地があります。

加えて、関西で腰を据えたい人にも向いています。大阪拠点は地場の大手・中堅企業を現地で完結して支援するために設けられており、東京の案件に呼ばれ続ける形にはなりません。

まとめ

Unite Partners株式会社は、製造業を中心に戦略から実行までを担う創業5年目の独立系総合コンサルティングファームです。全案件が大手企業との直接取引で、少数精鋭のコンサルタントを営業専任チーム、社長直下のAI開発チーム、外部専門家ネットワークが支える分業が特徴です。少額から始める「プロサポ」と、エンジニアと組んでAI実装まで担う「うごラボ」が、案件の入口と実行の両方を支えています。組織づくりに関与する余地があるのは、正社員30名・2拠点という規模だからです。ステラキャリアズでは、各社の選考傾向を踏まえたご相談を承っています。

※本記事は2026年8月時点で作成しています。制度・人員規模・案件構成などは変更される場合がありますので、最新の情報は公式サイト等をご確認ください。
