株式会社ネオビスタ（NeoVista）とは？
事業内容・働き方・選考の傾向を解説【2026年版】

株式会社ネオビスタは、2024年11月に設立されたDX・AIコンサルティングファームです。特徴は入り方にあります。経営や業務のレイヤーからではなく、顧客の全システムのテーブルとマスタを接続してデータ層から入り、経営管理から業務改革、中期経営計画の策定、システム再編まで走り抜ける構造です。PEファンドの投資先を主な顧客とし、設立2年弱で組織を組み上げました。本記事では、事業内容・組織・働き方・選考の傾向を整理します。

会社概要

社名株式会社ネオビスタ（NeoVista, Inc）
設立2024年11月
代表者代表取締役 木村陽太
役員木村陽太、杉田大亮、鹿子木徹
資本金1億円
本社東京都港区六本木3-2-1 住友不動産六本木グランドタワー32階
社員数54名（2026年8月時点）
決算期10月
事業内容DX・AIコンサルティング

本社は六本木一丁目駅に直結するビルの32階に200数十坪の自社オフィスを構えています。設立から2年弱の規模でこの体制を持つ点が、組織の立ち上げ方を示しています。

その会社を立ち上げたのが、代表の木村陽太氏です。アクセンチュアでの勤務とPEファンドでの投資経験を重ねたキャリアを持ちます。直前はPEファンドの執行役員として約8年間投資を担当しました。ファンド在籍時に、コンサルティング会社を買うよりゼロからつくった方が早いという構想を社内で提案したものの、バイアウトではないため実現しなかった経緯があります。その構想を自ら会社として立ち上げたのがネオビスタです。ファンド側の視点とコンサルティング側の実装力を最初から併せ持つ設計になっています。

事業内容と特徴

ネオビスタの事業は、5つの段階が連なります。第1段階は全システムのテーブルとマスタの接続で、設計図がなくても自力で繋ぎます。ここが全案件の入口です。第2段階は経営管理とFP&Aで、数字がタイムリーに見える状態をつくります。多くの案件が広がるのもこの段階です。第3段階が業務改革で、営業改革、マーケティングの効果測定、生産計画や製販連動へ横展開します。第4段階が中期経営計画の策定、第5段階がITシステムの再編です。テーブルとマスタから業務パターンを書き起こせるため、BPRの前工程を省いて進められます。

この入り方が他ファームとの違いです。大手ファームは経営や業務のレイヤーから入り、顧客側のベテランを軸に若手が業務ヒアリングを重ねます。ネオビスタはそれを非効率で解像度も上がりにくいと捉え、データ層から入ります。

その受注の方針も明確です。業務伴走や手軽なPMOは受けず、プロジェクト単位で受注します。

こうした進め方の実績として、大手が撤退した案件を引き受けて完遂したものが複数あります。ある食品メーカーでは、他社が作った可視化の仕組みが更新できず、作り直しに毎回3か月かかる状態で行き詰まっていました。競合が一度受注してから手を引いた案件をネオビスタが引き受け、生産管理と販売管理を全接続して3か月半で可視化を完成させ、その後は営業戦略、マーケティング戦略、中期経営計画まで支援範囲が広がりました。

また、ある電子部品メーカーでは、少量多品種で国内4工場と海外1工場のシステムが別々という状態でした。個別標準原価計算のためにはデータ基盤が先だと提言したものの一度失注し、2か月後に各工場で毎日更新される60個のExcelが生まれて運用が回らなくなり再依頼を受けています。データ基盤を4か月半で導入し、現在は製販連動を支援しています。

このほか、導入済みのデータ基盤がまったく使われていない電力会社では、どうすれば使う状態になるかという業務側からの改善を約半年で担いました。アウトドアメーカーでは、PMIで構築された連結パッケージが限界を迎えており、全面をデータ基盤側へ移行しています。続けて、国内100万会員の掘り起こしに向けたマーケティング戦略立案と施策効果検証プラットフォームの構築へ進みました。取引先400社・約2,000契約のリカーリング収益が管理されていなかったHR系SaaSでは、過去データまで遡ってフラグ付けし、コホート別の残存契約を可視化しています。

一方、AI領域では実装まで含む依頼が増えています。決済領域では、PMOを生成AIで置き換える依頼を受け、ベンダー作成レポートを判定会議に持ち込むまでの作業の約7割を自動化するRAGを3か月で構築しました。レポートを投入するとスコアリングと改善指示が返り、繰り返すと合格水準に到達する仕組みです。AI関連プロジェクトは直近で4本前後が並走しており、社内にエンジニアリング人材を抱えています。

さらに、M&A領域も手がけます。事業のカーブアウト売却では、生産と販売が曖昧に混在する事業の切り取り線の設計とストラクチャリングを担いました。ロールアップのビジネスDDや、DX推進のための買収判断でビジネスDDとITDDを組み合わせた案件もあります。ただし地の利のない案件をゼロから調査するデューデリジェンスは極力受けない方針で、既に知見のある領域に限って受けています。

成長性・外部評価

ネオビスタの組織は、マネージングディレクターからマネージャーまでの管理職層を、ビジネスコンサルティングとテクノロジーの両面で揃えています。

その運用の特徴は、部門を切らないことです。テクノロジーコンサルティング部のような部門を置かず、ビジネス・データ・テクノロジーの人材を1つのプールから組み合わせてデリバリーします。食品メーカーの可視化を3か月半で完遂できたのは、このチーム編成によるものです。

この編成とあわせて、品質の担保にも方針があります。マネージャー以上とスタッフの比率を1対3程度に保つという運用です。人数を増やす前に上位層を厚くする順序を取っています。

その上位層を見ると、MDはいずれも大手ファームやファンドでの実務経験者です。ビジネスコンサルティングを担うMDはアクセンチュアに16年在籍し、MDの一歩手前まで到達してから2025年に参画しました。テクノロジーコンサルティングを統括するMDは、新卒で入社したコンサルティング会社で内部統制を担当し、その後開発を経験しました。別のコンサルティングファームには12年在籍してパートナーまで昇進し、2025年に参画しています。データとAIの領域に強みを持ちます。

働き方・カルチャー

フルフレックスでコアタイムがありません。平日20日であれば月160時間を満たせばよい運用で、報告会の前に12時間働き、終わったら午前で帰るという働き方も許容されます。

また、ファンドの投資先を主な顧客としながら消耗しにくい点も特徴です。ファンド側の事情を理解している組織であるため、過剰な要求にも正面から議論できます。加えて先にデータ基盤をつくるため、依頼された数字を即時に出せます。徹夜を前提とした作業が発生しにくい設計です。

一方、求められる立ち位置は明確です。顧客と関係を深めながら伴走してフィーを積み上げていくスタイルではなく、アドバイザーとして意見する立場が期待されます。顧客の要望を聞いて形にする働き方から、意見して動かす働き方への転換が必要になります。

さらに、領域が固定されないことも前提です。インダストリーもテーマも案件ごとに変わるため、この幅広さを楽しめるかが分岐点になります。

このほかマネージャー以上には、次世代への承継が期待されています。事業経営そのものに携わりたい人には、役割が回ってきます。

キャリアパス・育成

ネオビスタの職位は7階層です。アナリスト、アソシエイト、シニアアソシエイトと上がり、マネージャー、シニアマネージャーへ進みます。その先がディレクターとマネージングディレクターです。

その入社時のレイヤーは、経歴で変わります。テクノロジーの経験がありコンサルティング未経験の場合は、アソシエイトから始まります。コンサルティングもテクノロジーも未経験の場合はアナリストまたはアソシエイトで、コンサルティング経験者はシニアアソシエイトからシニアマネージャーの範囲です。ディレクターはビジネスディベロップメントを自力でできると判断できる場合に対象になります。

この配置と並行して、研修も実務に寄せています。ロジカルシンキングなどの基礎に加え、実践研修の柱は事業性評価と財務分析です。財務モデリングは投資銀行のジュニア水準まで踏み込み、LBOモデルを組めるメンバーが複数在籍します。DXスキルで重視するのはデータモデリングです。未経験者にもツールを使って着手させます。教材は市販のものではなく現場のデータを使ったものに作り直しが進んでいます。

その結果として、若手でも上流から下流まで通しで経験できます。2025年入社で社会人1年目のメンバーが、食品メーカーのデータ基盤構築を顧客のCIOと対峙しながら3か月で完遂した例があります。

向いている人

データから事業を読み解きたい人に向いています。全システムのテーブルとマスタを接続して数字が見える状態をつくることが、全案件の入口です。データを扱う能力が、そのまま案件の起点になります。設計図がないシステムを自力で繋ぐ経験を積めます。

また、上流から下流まで通しで経験したい人にも合います。データ接続から経営管理、業務改革、中期経営計画の策定、システム再編までが一つの流れです。設立1年強で複数社が中期経営計画のフェーズに到達しています。若手でも顧客のCIOと対峙する機会があります。

さらに、構想で終わらせたくないAI人材にも向いています。AI案件は実装できる前提で依頼が来ており、PMOを生成AIで置き換える案件のように、業務の7割を自動化する仕組みを実際につくる仕事があります。社内にエンジニアリング人材を抱えているため、提案と実装が分断されません。

このほか、財務の地力をつけたい人にも合います。実践研修に置いているのが、事業性評価と財務分析です。財務モデリングは投資銀行のジュニア水準まで扱います。ビジネスとテクノロジーとコンサルティング経験の3点が揃えば、事業会社の経営企画でも起業でも通用するという育成の考え方が背景にあります。

加えて、領域を固定せず幅を取りたい人にも向いています。部門を切らず1つのプールから編成するため、インダストリーもテーマも案件ごとに変わり、幅広く経験できます。専門を一つに絞りたい人よりも、対応できる範囲を広げたい人に合う環境です。

まとめ

株式会社ネオビスタは、データ層から入って経営管理・業務改革・中期経営計画・システム再編まで一気通貫で担うDX・AIコンサルティングファームです。2024年11月の設立から2年弱で管理職層を揃え、大手が撤退した案件を引き受けて完遂した実績を複数持ちます。部門を切らないワンチーム運用、フルフレックスでコアタイムなしの働き方、投資銀行のジュニア水準まで踏み込む財務研修が特徴です。ステラキャリアズでは、各社の選考傾向を踏まえたご相談を承っています。
