ドリームインキュベータとは？
事業内容・働き方・選考の傾向を解説【2026年版】

株式会社ドリームインキュベータは、2000年に設立された戦略コンサルティングファームです。東京証券取引所プライム市場に上場し、事業創造や成長戦略を支援するビジネスプロデュース事業と、スタートアップへ投資育成を行うインキュベーション事業を営みます。本記事が扱うのは、コンサルティングにあたる前者のビジネスプロデュース事業です。同事業の売上高は2026年3月期に67億8,000万円まで伸び、現場に立つビジネスプロデューサーは2026年6月末で約170名になりました。事業内容・成長性・働き方・選考の傾向を整理します。

会社概要

社名株式会社ドリームインキュベータ
設立2000年6月1日
代表者代表取締役社長 三宅 孝之
本社東京都千代田区霞が関3-2-6 東京倶楽部ビルディング4F・6F
資本金50億1,900万円
従業員数約220名（連結・2026年3月末時点）
事業内容ビジネスプロデュース、インキュベーション
上場市場東京証券取引所プライム市場（証券コード4310）

上場しているのは、コンサルティングを担う会社そのものです。持株会社を置く形ではなく、上場会社自身がコンサルティングを担い、決算ではビジネスプロデュースセグメントとベンチャー投資セグメントの2つを開示します。連結の売上高や利益には投資事業の損益が混ざるため、本記事で示すコンサルティングの数字は、ビジネスプロデュース事業のセグメントに限っています。2023年1月にはアイペットホールディングスの全株式を譲渡し、この事業へ経営資源を集めました。

この会社の性格を決めているのが、経営陣の来歴と理念です。代表取締役社長は経済産業省とコンサルティング業界を経てDIに参画し、「産業プロデュース」「ビジネスプロデュース」というコンセプトを確立しました。ミッションは「社会を変える 事業を創る。」で、バリューは「枠を超える。」です。

事業内容と特徴

ドリームインキュベータのコンサルティングは、産業プロデュース＆ビジネスプロデュース、ストラテジー＆インストレーション、テクノロジー＆アンプリファイ、グローバル戦略共創という4つの領域に分かれます。ビジネスプロデュースという言葉が指すのは、社会課題や産業構造の変化から事業機会を見つけ、構想と戦略を描くところから始まる一連の動きです。そこにパートナーや技術、資本、人材を結びつけ、事業化まで進めます。

この中核にあたるのが、産業プロデュース＆ビジネスプロデュースです。固定フィーに加えて、成功報酬や投資を絡めた収益モデルも実装しています。セグメントの事業内容には、戦略コンサルティングとM&A支援、ソーシャルインパクトボンドが並びます。

一方、ストラテジー＆インストレーションが受け持つのは、新規事業に限らない包括的な経営課題です。戦略立案で区切らず、企業変革や業務改革の実現までを一体で伴走します。

この実行の局面をテクノロジーの側から支えるのが、テクノロジー＆アンプリファイです。製造業のDX、サプライチェーン改革、IT内製化の支援、業務改革に伴うAI・データ実装を扱います。戦略の段階から入るため、PMOだけを請け負う形は採りません。特定のパッケージ製品の導入を前提としない立場も取っており、顧客に選択肢を残せます。

残る一つのグローバル戦略共創は、ビジネスプロデュースの考え方を海外へ広げる役割を負います。インドの事業基盤を強めながら、グローバルサプライチェーン改革や観光インバウンド領域にも手を伸ばしています。

こうした4領域の外側に、産業レベルの取り組みがあります。2025年8月には山口フィナンシャルグループらとともに、山口県が設置した新事業創出・育成タスクフォースへ構成企業として参画しました。山口県は2026年4月にGX戦略地域の有望地域へ選ばれています。海外ではJICAの受託調査を担い、インドネシアの水素・アンモニア社会に向けたロードマップ策定を支援しました。

実際のプロジェクトは、構想から実装までの幅を持ちます。エンジニアリング会社のインド事業拡大では、M&A戦略の立案から交渉、PMIまでを一続きで支援しています。総合IT企業の知財部門では、エージェント型AIの企画から導入までを担いました。インフラ系エンジニアリング会社の業務プロセス改革では、約20%の生産性向上に結びついています。

この幅を支えているのが、業界を固定しないアサインです。プロジェクトの配属でインダストリーを絞る運用を置いていないため、担当する業界もテーマも案件ごとに変わります。

成長性・外部評価

ドリームインキュベータのビジネスプロデュース事業は、4期続けて売上を伸ばしています。2026年3月期の売上高は67億8,000万円で、前期比24%増となりました。営業利益は8億1,000万円、営業利益率は12%です。期初計画に対する達成率は109%でした。2022年3月期の26億円と並べると、4年で2倍を超えた計算になります。

背景には、顧客の大型化と長期プロジェクトの獲得があります。デジタル・ITテーマを中心に受注が積み上がり、2027年3月期第1四半期も売上高16億6,000万円と前年同期比22%増で立ち上がりました。同四半期はテクノロジー＆アンプリファイ領域が伸びています。

この伸びは人員にも表れています。ビジネスプロデューサーの数は2022年3月末の約60名から、2026年6月末には約170名まで増えました。

さらに、外部との組み方も広がっています。2026年5月には電通総研およびIFSジャパンと、製造業の生産管理とサプライチェーン最適化で戦略的協業に入りました。資本業務提携の相手には電通グループと山口フィナンシャルグループが並びます。2026年7月には、テクノロジー＆アンプリファイの立ち上げで培った企業変革の知見を書籍にまとめ、ダイヤモンド社から出しました。

この延長線上で、2026年5月に開示した5か年目標では、2030年3月期に売上高110億円以上、営業利益率15%以上を置いています。

働き方・カルチャー

ドリームインキュベータのオフィスは、モニターを備えたフリーアドレス制です。集中席やテレワークブースがあり、全国のサテライトオフィスも使えます。

この環境の上に、全社で顔を合わせる場が置かれています。毎月1回の全社ミーティングには全社員が参加し、プロジェクトの状況やナレッジを横断で共有します。年1回の社内表彰「DI Award」は、5つの賞を置いた全社員参加の投票型です。部門を超えた交流には費用の補助も付きます。

さらに、会社を離れた人とのつながりも残しています。アルムナイとのトークセッション「DIalog」を開き、社外に出たメンバーとの接点を保ちます。

そのほか、資産形成と生活を支える制度もあります。従業員持株会と自社株交付制度（ESOP）、選択制退職金制度があり、借上社宅制度やベビーシッター割引も利用できます。

この制度の効き方は、数字にも表れています。2026年3月期の男性の育児休業取得率は85.7%で、女性の取得率と復帰率はいずれも100%でした。女性比率は30.2%です。ベトナムとインドの拠点のスタッフも、本社メンバーとともにグローバルプロジェクトに入ります。

また、業務の側ではAIツールの導入が進んでいます。AI研修や語学研修の支援も置かれています。

キャリアパス・育成

ドリームインキュベータのキャリアパスは、産業と機能を横断しながら広げていく形です。特定分野や領域への専門特化・縦割り化を促す職種の分化を行わず、個人の適性と希望に応じて進む道を選べます。

この横断を支えるのが、体系化された研修です。入社時研修では、思考力と調査・分析力、アウトプット力、仕事への向き合い方をベーススキルとして学び、最後に模擬ケースで通しの演習を行います。スキルアップ研修は、プレゼンテーションやクライアントコミュニケーションといったソフトスキルと、業務改革・プロジェクトマネジメント・業界知識・先端テクノロジーのハードスキルに分かれます。マネジャー研修で加わるのは、高難度プロジェクトを動かすケースマネジメントと、信頼関係を築くクライアントマネジメントです。

この研修と並んで、日々の相談先も決まっています。人材育成の専門チームが全社員に個別のメンターを選び、業務とキャリアの相談に定期的に応じます。

その先にある昇格の機会は、評価・レビュー会議で開かれます。会議のサイクルは四半期です。次の職位へ上がる機会が、そのつど設けられます。評価の軸はビジネスプロデューサーとして創出した成果で、職位ごとの期待役割と成果に加えて、組織への貢献やマインドセットの水準も見ます。

この評価の中身も、足元で入れ替わっています。AIの活用を前提に、調査・分析力よりも構想力と実行力を重く見る体系へ切り替え、研修の内容も刷新しました。

また、タイトルの呼称は戦略側とテクノロジー＆アンプリファイ側で異なります。テクノロジー＆アンプリファイはディレクター、マネージングディレクターと上がり、その先が執行役員です。戦略側はシニアマネージャーの次が執行役員にあたります。

中途選考の傾向

ドリームインキュベータの中途選考は、応募する職種によって流れが変わります。募集しているのは、ビジネスプロデューサーと、テクノロジー＆アンプリファイのプラクティス採用です。

このうちビジネスプロデューサーの選考は、書類選考 → 一次面接 → 二次面接（役員） → 三次面接（社長）という流れです。一次面接は2部構成で、続けて2時間受ける形が基本になります。分けて受けることも選べ、その場合は面接が4回になります。

一方、テクノロジー＆アンプリファイの選考は、書類選考 → 面接3〜4回 → 内定という流れです。最終面接は、同領域を統括する執行役員が担当します。

この2つに共通して、ケース面接が置かれます。ビジネスプロデューサーはケース面接が中心で、テクノロジー＆アンプリファイでは思考力の確認が主眼です。見られるのは、論理的思考力と思考体力、そして社内外を巻き込んで動かす力です。

向いている人

戦略を描くところで終わらせたくない人に向いています。支援の範囲は、構想から実装までが一続きです。M&Aなら戦略立案から交渉とPMIまで、同じチームが追いかけます。DXでもビジョン策定から実行伴走までを担うため、描いたものが動くところまで見届けられます。

さらに、産業や社会の単位で仕事をしたい人にも合います。金融機関や自治体、JICAと組んだ産業育成や国際協力のテーマがあり、企業1社の枠を超えた構想に関われます。官公庁との連携は、産業プロデュースという看板の中身そのものです。

また、テクノロジーで変革を実装まで届けたい人にも向いています。テクノロジー＆アンプリファイは戦略の段階から入り、特定のパッケージ製品の導入を前提としません。構想と実装の間の分断を見てきた経験が、そのまま生きます。

加えて、担当する業界を固定したくない人にも合います。職種の分化を置かず、アサインでもインダストリーを絞らないため、案件ごとに業界とテーマが変わります。

この横断性を、事業会社や官公庁からの転身で活かす道もあります。2026年3月期の中途採用比率は76.1%で、コンサルタント以外の経歴を持つ人材を積極的に採っています。求められるのは、何かしらの軸での専門性と、人とは違う経験です。

まとめ

ドリームインキュベータは、東証プライム市場に上場する戦略コンサルティングファームです。コンサルティングにあたるビジネスプロデュース事業の売上高は2026年3月期に67億8,000万円まで伸び、ビジネスプロデューサーは2026年6月末で約170名になりました。構想から実装までを一続きで担い、産業や社会の単位でテーマを立てるところに仕事の輪郭があります。ステラキャリアズでは、各社の選考傾向を踏まえたご相談を承っています。
