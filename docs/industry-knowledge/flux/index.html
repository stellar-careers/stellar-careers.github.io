株式会社FLUXとは？
事業内容・働き方・特徴を解説【2026年版】

株式会社FLUXは、2018年に東京で創業し、企業のAIトランスフォーメーション（AX）を支援するスタートアップです。コンサルティングファームではなく、AIとDXのプロダクトを自社で持つ事業会社です。2026年5月にはシリーズCのファーストクローズで60億円を調達し、累計調達額は約160億円になりました。本記事では、FLUXの事業内容と働き方を公開情報から整理します。

会社概要

社名株式会社FLUX（FLUX Inc.）
設立2018年5月
代表者代表取締役CEO 永井元治
本社東京都港区赤坂9-7-1 ミッドタウン・タワー24階
従業員数（連結）約650名（2026年8月末時点）
事業内容事業変革支援、採用支援、マーケティング支援
累計調達額約160億円（2026年5月時点）
主要投資家DNX Capital、Archetype Ventures ほか

株式会社FLUXは、ベンチャーキャピタルからの出資を受けて成長してきた未上場企業です。ミッションは「日本経済に流れを」で、AI時代における企業のベストパートナーになることをビジョンに置いています。

この従業員数は連結の数値で、グループの事業会社の人員も含みます。本社は2025年6月に渋谷から東京ミッドタウンへ移りました。

こうした会社を率いるのは、創業期から続く経営陣です。代表取締役CEOの永井元治はベイン・アンド・カンパニーの出身で、取締役CTOのEdwin Liは東京大学大学院の松尾研究室で機械学習を学びました。

事業内容と特徴

FLUXの事業は、事業変革支援・採用支援・マーケティング支援の3領域にわたります。それぞれFLUX Insight、FLUX Agent、FLUX Marketingとして提供し、戦略の立案から実行、人材の採用・育成までをつなげます。

この中核にあるのがFLUX Insightです。支援範囲はBX（事業変革）とTX（技術変革）の2つで、BXでは戦略立案や新規事業開発、業務改善、内製化支援を扱います。TXが担うのはAI・データ基盤の構築やシステム開発、セキュリティ方針の策定です。事業責任者や大手コンサルティングファームの出身者と、AIに精通した技術者が同じチームに入ります。

こうした支援の形を、FLUXはAIイネーブルメントパートナーと呼んでいます。中心にいるのはFDE（Forward Deployed Engineer）です。ビジネスとAI技術の双方を理解して顧客の現場に入り、自社でAIを開発し使ってきた知見を持ち込みます。人材紹介チームが内製化まで引き受ける点も、この立ち位置を支えています。

さらに、支援に使うプロダクトも自社で開発しています。FLUX Workflowは複数のLLMや外部システムをつなぎ、業務を自動化するノーコードのAIワークフローです。2025年9月には日本語性能を高めた大規模言語モデルのFLUX Japanese LLMを公開し、金融業界に特化したモデルも作りました。

一方、FLUX AgentとFLUX Marketingは、人が担ってきた領域をAIで組み替える事業です。前者はミドル・ハイレイヤー層向けの人材紹介で、AIマッチングのFLUX Matchを併用します。後者はブランド形成から広告運用までを扱います。

成長性・外部評価

FLUXの資金調達は、2019年10月のシードラウンドから積み上がり、累計で約160億円に達しました。直近は2026年5月のシリーズCファーストクローズで、増資とセカンダリー取引を合わせた60億円です。リード投資家はJICベンチャー・グロース・インベストメンツで、NTTデータやSalesforce Venturesなども引受先に加わりました。

この調達の背景には、事業の伸びがあります。2026年4月の時点で、月次売上高は前年同月比で約3.1倍、従業員数は約2.3倍で推移しました。導入は金融やIT、通信、製造などのエンタープライズ企業が中心です。

こうした成長と並行して、外部からの評価も重ねてきました。2021年には週刊東洋経済の「すごいベンチャー100」に、2022年にはForbes JAPANのJapan's Cloud 20に選ばれています。2026年8月には、経営者や有識者を招いた日本AI立国会議を自社で主催しました。

働き方・カルチャー

FLUXの働き方は、オフィスへの出社とリモートワークを組み合わせたハイブリッド勤務です。出社日数は部署によって変わります。本社の東京ミッドタウンには会議室に加えて一人用の個室ブースがあり、外出の多い部署にはサテライト型シェアオフィスも用意しています。

また、育児や介護と仕事を両立できるようフレックスタイム制度を導入しています。転勤はありません。副業も、業務に支障のない範囲であれば申請のうえで認められます。

こうした制度を支えるのは、変化を前提に置くカルチャーです。日々の判断軸となるバリューには「80 / 20」や「Quick and Small」が並びます。半年に一度は全社員が集まる総会があり、会社が費用を補助する部活動も部署をまたぐ接点になっています。

キャリアパス・育成

FLUXの育成の土台は、バリューを軸に組んだ成長支援プログラムです。入社直後には10日間のオンボーディングがあり、バリューの理解を中心に早く組織になじむための知識を学びます。事業部・職種ごとに組まれた研修も並行して受けられます。

この中で職種を問わず全員が受けるのが、FLUX-FDE研修です。入社1か月目にAIの基礎からAIエージェントの構築までを集中講義で学び、ビジネス職やコーポレート職も含めてAIを使いこなす人材を目指します。

こうした研修の後に続くのが、日々の業務の中での対話です。全メンバーが上長と月1回のGrowth 1on1を持ち、バリューに基づいて行動を振り返りながら次の一歩を決めます。毎週金曜日には本部ごとにWin-Sessionが開かれ、その週の行動や成果をバリューと結びつけて称え合います。

さらに、リーダーを目指す人に向けて用意されているのが次世代リーダー研修です。自主応募制で審査を経て参加し、ビジネスやスポーツの分野で活躍する外部講師のセッションなどを通じて、リーダーシップに必要な考え方を身につけます。評価にもバリューが組み込まれており、研修や1on1で磨いた行動がそのまま評価の軸になります。

向いている人

AIを軸にキャリアをつくりたい人に向いています。FLUXは支援の現場でAIを使うだけでなく、大規模言語モデルやAIワークフローを自社で開発しており、技術に触れる機会がビジネス側にも開かれています。

また、戦略の立案だけでなく実装と定着まで見届けたい人にも合います。FLUX InsightはBXとTXの両面を持ち、FDEが現場に入って構想を形にします。

さらに、複数の事業を横断して経験を広げたい人にも向いています。性格の異なる3領域が同じ会社の中にあり、希望による異動の道もあります。

このほか、コンサルティングファームか事業会社かという二択に収まらない働き方を探している人にも合います。顧客の変革に伴走しながら、自社のプロダクトづくりにも関われます。

まとめ

株式会社FLUXは、2018年5月に創業し、AIトランスフォーメーションを軸に企業の変革を支援するスタートアップです。事業変革支援のFLUX Insightを中心に、採用支援とマーケティング支援を加えた3領域を持ちます。AIワークフローや日本語の大規模言語モデルは自社で開発しました。2026年5月のシリーズCで累計調達額は約160億円となり、従業員数は連結で約650名まで広がりました。AIを前提に事業と組織を組み替える現場へ、コンサルティングと技術の両面から関われる点が特徴です。ステラキャリアズでは、各社の選考傾向を踏まえたご相談を承っています。
