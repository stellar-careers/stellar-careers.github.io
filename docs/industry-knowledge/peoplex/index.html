PeopleXとは？
事業内容・働き方・選考の傾向を解説【2026年版】

PeopleXは、AI面接をはじめとする対話型AIのプロダクトを開発し、人事領域と営業領域で企業の課題解決にあたる事業会社です。2024年4月に創業したスタートアップで、2025年5月までに累計23.7億円の資金を調達しました。コンサルティングファームではなく、自社プロダクトに研修などのサービスを組み合わせて、企業の採用から育成までを支えています。本記事では、事業内容と働き方、選考の傾向を公開情報から整理します。

会社概要

社名株式会社PeopleX（英文: PeopleX Inc.）
創業2024年4月1日
代表者代表取締役CEO 橘 大地
本社東京都新宿区西新宿2-6-1 新宿住友ビル24階
拠点池袋オフィス、大阪オフィス、名古屋オフィス、ベトナム現地法人
従業員数連結 約140名（2025年4月時点）
事業内容人事領域・営業領域のAIプロダクトの開発・提供
認証ISO/IEC 27001:2022

代表の橘大地は弁護士で、サイバーエージェントとGVA法律事務所で企業法務に携わった後、2015年に弁護士ドットコムへ入社しました。同社ではクラウド契約サービス「クラウドサイン」の事業責任者を務め、2019年には取締役に就いています。

その経営を支える役員には、住友商事やユーザベースで財務と経営管理を担ってきたCFOや、マイナビで執行役員を務めたCSOがいます。CTOは2024年4月に同社を共同で創業したメンバーで、AI面接やPeopleWorkの開発を担います。

なお、社名の似たエンPeopleX株式会社は、2026年4月にエン株式会社と設立した合弁会社です。PeopleXのAIプロダクトのOEM販売などを担う法人で、PeopleX本体とは別の会社にあたります。

事業内容と特徴

PeopleXの事業の中心は、採用から入社後の育成・面談までを対話型AIで支えるプロダクト群です。AI面接はデジタルヒューマンが面接官を務める対話型のサービスで、候補者は24時間いつでも面接を受けられます。新卒・中途の採用に加え、パート・アルバイトの採用にも使えます。

この対話の技術を入社後の場面へ広げたのが、AIロープレとAI面談です。AIロープレでは、営業や接客、1on1などの練習を、時間を選ばずAI相手に行えます。AI面談は1on1やキャリア面談をAIとの対話で行うサービスで、就業規則などを学習させれば社員の質問にも答えられます。

さらに、個々のプロダクトを連携させる人事領域の総合型AIエージェント基盤として、PeopleX AgenticHR プラットフォームを開発しています。2026年7月には営業組織科学総合研究所を、8月には人事組織科学総合研究所を、それぞれ社内の研究機関として設けました。いずれも商談や面接、面談などのデータをAIで解析し、得た知見をプロダクトへ還元します。

こうしたAIプロダクトの外側にも、人事の実務に近い事業があります。PeopleX マネジメントコンサルティングは、AIによる研修前後の診断と研修の実施を組み合わせた、同社自身の育成支援サービスです。エンプロイーサクセスHRプラットフォームのPeopleWorkや、人事・労務書籍の読み放題サービスのHR LIBRARYも運営しています。

背景には、複数の事業を掛け合わせて顧客への価値を広げるコンパウンド戦略があります。採用からオンボーディング、面談、育成までを一気通貫で支えることで、候補者や社員との接点から得た情報を次の場面へ生かしています。

また、AIが人の評価に関わる領域だけに、公平性への備えも事業の一部です。社内にはAI倫理委員会を自主的に設け、評価ロジックや運用フローをリリース前に倫理と公平性の観点から点検しています。2025年4月に創設された事業者団体、AIによる採用面接・人事評価サービス協議会（AIAC）では、同社が代表理事を務めます。

成長性・外部評価

PeopleXの累計資金調達額は、2025年5月時点で23.7億円です。2024年6月のシードラウンドではWiLをリードインベスターに16.1億円を調達し、2025年5月にはデットファイナンスで7.6億円を加えました。

このシードラウンドには、Angel BridgeやOne Capital、UB Venturesなどのベンチャーキャピタルに加え、起業家を中心とする個人投資家も出資しました。創業から2か月の段階で、複数の投資家から16億円を超える資金を集めたことになります。

その後の事業の広がりは、導入社数に表れています。グループ全体のサービス群の累計導入社数は、2025年10月に3,000社を超えました。

さらに、金融機関や人材サービス会社との協業も広がっています。2025年10月にはSMBCグループのプラリタウンとの提携で、受付業務向けの対話型AIサービス「プラリワーカー」の提供が始まりました。2026年1月にはみずほ銀行と人的資本経営の支援で連携し、同年4月にはエンとの合弁会社を立ち上げています。AI面接そのものも、日経ビジネスや読売新聞、NHKの番組などで取り上げられてきました。

働き方・カルチャー

PeopleXは、働く時間と場所を柔軟に選べる会社です。勤務はフルフレックスタイム制か専門業務型裁量労働制のいずれかで、どちらもコアタイムがありません。リモートワークはビジネス職で一部可能で、出社日数は上長と相談しながら決めます。エンジニア職はリモートを中心に、月1回の出社が目安です。

こうした働き方の土台にあるのが、人事制度「People Trust Package」です。社員を信じて主体性を引き出すという考え方に立ち、試用期間を設けず、髪型や服装も自由にしています。慶弔休暇は事実婚・同性婚にも適用され、ペットとの別れに使える忌引き休暇もあります。

また、ストックオプション制度があり、AIサービスの利用手当も支給されます。AIを顧客へのサービスだけでなく自社の組織運営にも取り入れる方針があり、手当はその方針に沿った制度といえます。

さらに、2026年4月からは人的資本に関する情報を自主的に開示しています。非上場企業でありながら、国の人的資本可視化指針の改訂版に沿って、人事戦略とその指標を社外へ示しました。

キャリアパス・育成

PeopleXの育成は、採用した人材が短期間で事業や顧客、プロダクトを理解し、自ら価値を生み出せるようになることを重視しています。AIを活用した実践的な学習の機会を通じて、職種ごとの立ち上がりを早め、マネジメントを担う人材も育てる方針です。

その特徴は、自社のAIプロダクトを社内の人事運営にも使っている点です。入社後の面談にはAI面談を用い、課題を早い段階でつかんで改善につなげます。マネジメント力はAIロールプレイングで可視化し、全社員を対象とする社内マネジメント資格の認定制度で、管理職に求める水準を明確にしています。

また、同社が中核人材として重点的に採用・育成・配置するのは、エンジニアと事業開発人材、そして各事業を自律的に動かす責任者人材です。事業の責任者を担う人材を育成の対象に明記している点は、早い段階から事業を任されたい人にとって意味のある方針といえます。

さらに、2026年4月には専門役員という職位を新設しました。専門役員は組織マネジメントの枠にとらわれず、特定の専門領域でプロジェクトやチームを率います。管理職として組織を束ねる道とは別に、専門性を軸に経営へ近づく道が示されたといえます。

中途選考の傾向

PeopleXのエンジニア職の選考は、カジュアル面談 → コーディングテスト → 一次面接 → 二次面接 → 最終面接という流れです。一次面接はCTO、最終面接はCEOが担当し、現場エンジニアによる二次面接は場合に応じて行われます。

このうちコーディングテストは、メールで課題を提出する形式です。面接に進む前に、書いたコードで力を示せる段階といえます。職種によって流れは少しずつ異なり、コーディングテストのない職種もあります。

向いている人

AIを使った人事の仕組みを、プロダクトとして社会に広げたい人に向いています。PeopleXは採用から育成、面談までを対話型AIでつなぐプロダクト群を持ち、グループ全体のサービス群の累計導入社数は3,000社を超えました。

また、人事や人材サービスの実務経験を事業に生かしたい人にも合います。同社は研修・組織開発のサービスを自社で運営しており、AIプロダクトと組み合わせて企業を支援する点が特徴です。現場で培った知見を生かせる場面が多い環境といえます。

さらに、立ち上げの速い環境で事業をつくる側に回りたい人にも向いています。創業から2年あまりで複数のAIプロダクトを世に出し、M&Aや合弁によって事業の幅を広げてきました。各事業を自律的に動かす責任者人材を中核に位置づけている点も、その裏づけといえます。

このほか、エンジニアとしては、3Dアバターによるリアルタイムの音声対話をエンタープライズ品質で実装することに挑みたい人に合います。音声やネットワーク、推論、UIの境界をまたいだ設計に取り組める環境です。

まとめ

PeopleXは、対話型AIで企業の採用から育成までを支えるプロダクトを開発する、2024年創業のスタートアップです。AI面接を起点にAIロープレやAI面談へと領域を広げ、グループ全体のサービス群の累計導入社数は2025年10月に3,000社を超えました。働き方はコアタイムのないフルフレックスタイム制か裁量労働制が基本で、ストックオプション制度もあります。ステラキャリアズでは、各社の選考傾向を踏まえたご相談を承っています。

※本記事は2026年8月時点で作成しています。制度・人員規模・案件構成などは変更される場合がありますので、最新の情報は公式サイト等をご確認ください。
