キャディ（CADDi）とは？
事業内容・働き方・選考の傾向を解説【2026年版】

キャディは、製造業向けの「製造業AIデータプラットフォームCADDi」を開発・提供するスタートアップです。2017年に製造業の受発注プラットフォームで創業し、2024年にその事業をデータプラットフォーム事業へ統合しました。コンサルティングファームではなく、自社のプロダクトと顧客の現場への伴走を組み合わせて製造業の変革を担う事業会社です。本記事では、事業内容と働き方、中途選考の流れを公開情報から整理します。

事業内容製造業AIデータプラットフォーム「CADDi」の開発・提供

記事で扱う会社は、東京に本社を置くキャディ株式会社です。海外には現地法人を置いており、2022年にベトナムとタイ、2023年に米国で設立しました。

このうち米国法人はシカゴに置かれ、現地の製造業に向けた営業や顧客支援を担います。ASEANではバンコクとハノイ、ホーチミンを拠点に、アジアの製造業へプラットフォームを届けています。以下で紹介する制度と選考は、日本のキャディ株式会社のものです。

事業内容と特徴

キャディの事業は、製造業AIデータプラットフォーム「CADDi」の開発と提供です。設計や調達、生産といったバリューチェーンの各所に散らばるデータをAIで解析・構造化し、組織全体で使えるデータ基盤に変えます。2026年8月には、データを取り込む層から業務を実行する層までをひとつの基盤の上に統合し、プラットフォームをゼロから再設計しました。

データ基盤図面やCAD、仕様書などの業務データを取り込み、独自技術で解析・構造化する
セマンティクスデータに意味と関連性を与え、AIと人が理解できる「データの地図」を描く
横断プロダクトCADDi Explorerが全社の業務データを横断して探索し、CADDi Agentが分析と判断を担う
業務特化プロダクト設計から製造・保全までの工程ごとに業務を支え、そこで生まれた判断をデータとして蓄積する

この構成の要は、業務のなかで生まれたデータが基盤に戻ってくる循環にあります。工程ごとのプロダクトで記録された判断や結果がデータの地図を厚くするため、使うほどAIの推論の精度が上がります。見積依頼から発注先の決定までを一元化するCADDi Quoteも、この工程別プロダクトのひとつです。

こうした製品群と並んで、キャディの専門チームが顧客の現場に入り込み、プロダクトの実装から組織への浸透、成果の創出までを伴走します。ソフトウェアを導入して終わりにせず、データの構造化から定着までを一体で担う考え方を、同社はWhole Productと呼んでいます。顧客の変革を担う職種が受け持つのは、経営課題の特定からプロジェクト設計、現場のチェンジマネジメントまでです。

このプラットフォームの土台には、創業期から手がけてきた部品の受発注・調達支援の事業があります。メーカーの図面を独自の技術で解析し、品質・納期・価格が最も合う加工会社を選んで、検査と納品まで一貫して担う事業でした。この事業を運営するなかで数多くのソフトウェアを内製してきたことが、現在のプロダクトの基になりました。

この事業と並行して、2022年6月には図面を中心とする製品データを探索する「CADDi Drawer」の提供を始めました。2024年7月に2つの事業の統合を決め、それまで手がけていた部品・組立品の提供を終えています。2026年8月に発表したCADDi Explorerは、図面中心だった探索の対象を、CAD・BOM・CRM・SCMからERPの会計情報、エクセルまで社内のあらゆる業務データへ広げました。

成長性・外部評価

キャディのプラットフォームは、国内外の製造業に導入が広がっています。2026年8月時点で、CADDi Drawerは日経225構成企業のうちディスクリート系製造業の過半数に導入され、22カ国の顧客に使われています。

また、資金調達の実績も重ねています。2023年7月にシリーズCで総額118億円を調達し、2025年3月にはシリーズCエクステンションとして40億円のエクイティ調達と51億円の長期デットファイナンスを実施しました。この時点の累計エクイティ調達額は257.3億円です。

さらに、海外での導入も進んでいます。2026年7月には、米国オハイオ州に本社を置く自動車部品サプライヤーでの活用事例を公開しました。

働き方・カルチャー

キャディの働き方の基本は、出社です。対面での議論とスピードを重視しており、出社の頻度はチームごとに異なります。フレックスタイム制も承認制で利用でき、首都圏以外に住みながら働くメンバーもいます。

また、社内では日本語と英語を併用しています。グローバルの全社会議やイベントは日英の両方で開かれ、重要な告知や文書も2言語で併記されます。全世界の従業員が参加するGlobal All-hands Meetingは、毎週オンラインでの開催です。

こうした組織の共通言語になっているのが、「大胆」「卓越」「一丸」「至誠」のバリューです。社内では役職や経験年数にかかわらず、何が正しいかをフラットに議論します。高い目標にも、チームで鼓舞し合いながら挑みます。

さらに、家庭と仕事の両立を支える制度もあります。2025年2月時点で社員の平均年齢は34.3歳、子育て中の社員の割合は43%でした。短時間勤務制度や看護・介護休暇のほか、女性特有の体調不良に対応するエフ休暇が用意されています。このほか、報酬の面ではストックオプション制度もあります。

キャリアパス・育成

キャディの評価は、ミッショングレード（MG）と呼ぶ等級制度を土台にした独自の制度HELIXで運用されています。2024年10月に中身を大きく改め、定量評価とコンピテンシー評価の2軸で成果と行動の両方を見るようになりました。評価は半年ごとの年2回で、部門をまたいだカリブレーションによって部署間の基準をそろえています。

この評価を成長につなげているのが、月次のフィードバック面談と、四半期ごとの目標設定面談です。入社時には、他部署の先輩がメンターとして付くナナメンター制度もあります。書籍の購入費は会社が全額を負担し、外部研修の費用も支援しています。

また、入社後はまず全社共通のオンボーディング研修で、製造業のドメイン知識と事業内容、カルチャーを学びます。その後は部署ごとの研修に進み、セールス部門では2025年に立ち上げたセールスイネーブルメントの組織が早期の立ち上がりを支えます。

さらに、キャリアの広げ方にも選択肢があります。2024年10月の改定で、マネジメントコースとプロフェッショナルコースの2軸でキャリアを捉える方針に移り、専門性を深める道も評価の対象として明確になりました。事業の成長フェーズに合わせて担当業務や部署を変える機会もあり、会社から打診するときは面談で本人の志向をすり合わせてから決めます。

中途選考の傾向

キャディの中途選考は、書類選考 → 面接1〜2回 → 最終選考（ワークサンプル面接） → 内定という流れです。職種を問わず、ミッションへの共感と、正解のない領域で自ら考え抜いて動く姿勢が重視されます。

向いている人

提案で終わらず、実装と定着まで顧客に伴走したい人に向いています。キャディでは専門チームがプロダクトの実装から組織への浸透までを伴走し、顧客の変革を担う職種が経営課題の特定から現場のチェンジマネジメントまでを受け持ちます。こうした職種では、コンサルティングファームで経営層と向き合った経歴や、事業会社で事業を推進してきた経歴が評価の対象です。

また、製造業の外で培った経験を持ち込みたい人にも合います。社内には、AIエンジニアやコンサルタント、商社の出身者など、多様なバックグラウンドを持つメンバーが集まっています。顧客の変革を担う職種で最も重視されるのは、課題を構造化し、プロジェクトを設計して実行しきる力です。

さらに、日本語と英語を併用する環境で働きたい人にも向いています。グローバルの会議や重要な文書は日英の2言語で運用され、米国とASEANの拠点とも同じ場で情報を共有します。

まとめ

キャディは、製造業のデータをAIで構造化し、組織全体の資産に変えるプラットフォームを提供する事業会社です。創業期の受発注事業で得た現場の知見を土台に、2024年にデータプラットフォーム事業へ一本化し、2026年8月にはプラットフォームをゼロから再設計しました。専門チームが顧客の現場で実装と定着まで伴走するため、コンサルティングで培った経験を事業会社の立場で生かせる環境といえます。ステラキャリアズでは、各社の選考傾向を踏まえたご相談を承っています。

※本記事は2026年8月時点で作成しています。制度・人員規模・案件構成などは変更される場合がありますので、最新の情報は公式サイト等をご確認ください。
