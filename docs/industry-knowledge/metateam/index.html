METATEAM（メタチーム）とは？
事業内容・働き方・選考の傾向を解説【2026年版】

METATEAM株式会社は、2006年に設立されたITコンサルティングファームです。旧社名はシアトルコンサルティングで、2023年4月に現社名へ変更しました。開発中心のSIerから、構想策定から実装までを担うDXコンサルティングへ事業を転換し、グループで950名規模まで拡大しています。社名にあるチームワークを組織運営の軸に置いている点が特徴です。本記事では、事業内容・組織・働き方・選考の傾向を整理します。

会社概要

社名METATEAM株式会社
旧社名シアトルコンサルティング株式会社（2023年4月1日に社名変更）
設立2006年5月18日
代表者代表取締役社長 京和将史
従業員数グループ全体で約950名（単体約880名、ミャンマー子会社約70名／2026年8月時点）
本社東京都港区南青山2丁目27番25号 ヒューリック南青山ビル9階
拠点東京（本社・サテライトオフィス）・大阪
資本金5,000万円
決算期4月（2026年5月からが第21期）
子会社METATEAM MYANMAR Co.,Ltd（2013年設立・オフショア開発拠点）

社名変更は、チームで時代を超えていく会社を目指すという趣旨で行われました。福利厚生に残るシアトルへの旅行補助は、旧社名に由来する制度です。

事業内容と特徴

METATEAMの事業は、数年で位置づけが変わりました。以前は5〜30名体制の開発案件を中堅企業から2次請・3次請で受け、他社が整えた要件に沿って実務を担う開発中心のSIerでした。現在は経営・業務課題に踏み込んだ提案から、構想策定と実装までを一気通貫で担うエンタープライズ企業のDX支援へ移っています。SIerとしての実行力を土台に、提案力を重ねてきました。

その顧客は上場企業が中心で、金融・通信・官公庁・製造・小売・不動産の各業界に広がります。案件の商流別構成は、エンド・事業会社が37%、大手SIが29%、情報子会社が17%です。役割の構成は、PM/PMOが40%、インフラSEが25%、アプリSEが20%、コンサルタントが15%となっています。

こうした商流のなかで、コンサルティング案件はプライムが目立ちます。大手ドラッグストアでは、POS起点からEC起点へ切り替えるCX推進のため、EC基盤の構想計画策定からRFP策定までを担いました。大手保険会社では権限管理システムのプロジェクト立ち上げと基幹システムのリプレイスを支援しています。大手リース企業では業務の全量棚卸と可視化を実施し、業務改善計画の策定から自動化を含む改善実装までを担いました。化学品専門商社のSaaS事業立ち上げで、カスタマーサクセス機能をゼロから設計した案件もあります。いずれも数人月から10数人月の規模で、パートナーからコンサルタントまで数名の体制です。

一方、AIには専門組織があります。AI戦略室が担うのは、AIエージェント開発、AI戦略コンサルティング、機械学習とMLパイプラインの構築、AIガバナンスの4領域です。エージェント開発ではLangGraph、RAG、マルチエージェントを扱います。不動産事業会社の生成AI PoC支援ではデータ整備からRAG構築まで手がけ、5〜6のアプリを実業務へ載せました。通信では速度の原因分析とエリア別予測モデルの構築・運用自動化を進めています。顧客支援・人材育成・自社実装を循環させる形で、自社向けAIエージェントの開発と運用も行っています。

成長性・外部評価

METATEAMの組織拡大は、年齢構成の変化に表れています。19期（2024年度）から21期（2026年度）の2年で、30代以上の人数が2倍を超えました。経験者採用によって、組織の中核層が厚くなっています。

その動きを支えているのが、外部との資本関係です。2023年9月には、東京証券取引所プライム市場に上場するLTS（株式会社エル・ティー・エス）と資本業務提携を締結しました。第21期のテーマは「超・顧客志向」です。

働き方・カルチャー

METATEAMの働き方では、案件によってフルリモートやハイブリッドの体制もあります。組織運営の軸に置いているのはチームワークです。プロジェクトとは別に組織体制ごとのチームを敷き、月1回そのチームで集まって勉強とナレッジ共有を行います。所属先が案件だけにならないため、周囲と密に連携して進めたい人に合います。

その象徴が、月1回の全社総会「メタチームサミット」です。社内で最も優先度の高い場と位置づけられており、活躍社員の表彰と発表、社長からの経営方針の共有が行われます。半年に一度は懇親会も開かれます。

このチームワークを言葉にしたのが、バリューの「TEAMS」です。前半はThanks（感謝を持って人と接する）、Engine（当事者意識を持ち主体的に提案・行動する）、All（利他の心を持って行動する）です。後半はMasterpiece（最高傑作と思えるアウトプットを出す）とStock（多くの時間を共有し信頼関係を築く）で、5つの頭文字を取っています。

このほか福利厚生には独自色があります。リモート手当や企業型確定拠出年金、書籍購入補助があり、入社日から有給付与までの間に使える特別休暇は3日です。結婚祝金、出産祝金とランドセル手当、資格取得時の受験料補助と報奨金もあります。シアトルやサンフランシスコへの旅行費を一部支給する制度と、VISA・パスポートの取得や更新に半日休暇を使える制度もあります。

キャリアパス・育成

METATEAMの職位は、アナリストからシニアパートナーまで8段階です。段ごとに役割と期待値が定義されています。シニアコンサルタントでプロジェクトや担当領域のリーダーを担い、マネージャーで提案からクロージングまでを推進します。シニアマネージャーで複数または大規模プロジェクトのマネジメントへ、アソシエイトパートナーでアカウントマネージャーとして顧客の新規開拓と拡大へ進む流れです。

その評価は成果・情意・能力の3軸です。成果は顧客満足と人材育成、情意はコミュニケーション、リーダーシップ、バリューの実践、能力は業務理解と課題解決で見られます。ジョブディスクリプションとレベルごとの評価シートが社内公開されており、各レベルの業務の期待値と処遇の基準を確認できます。評価面談のタイミングは半期と通期です。加えて月次の1on1でキャリア支援が行われます。

一方、キャリアの方向は一つではありません。SE、コンサルタント、PM、PMOという役割の間を、要件定義・アーキテクチャ設計・ベンダー管理・企画提案・課題特定・計画立案といった要素の組み合わせで移動できます。本人の志向とやりたいことに合わせて設計する方針です。

さらに、AIには段階的な育成の道筋があります。始まりは全社AIリテラシー研修です。そこから新人AI活用研修、AIエージェント開発研修（LangGraph開発、RAGエージェント、Tool/Guardrail/マルチエージェント）へ進みます。社内のAI教育コンテンツも継続的に配信され、研修で終わらせず実案件と自社実装で実践します。

このほかオンボーディングも仕組み化されています。面談内容を踏まえた配属と参画プロジェクトの検討が入社前から進み、入社後はオリエンテーション、部門長面談、所属チームでの1on1、毎月の交流イベントが続きます。

中途選考の傾向

METATEAMの中途選考は、応募 → 書類選考 → 一次面接 → 最終面接 → 内定という流れです。一次面接は採用担当がオンラインで行い、カルチャーとスキルの両面を確認します。最終面接の担当は役員または本部長クラスで、原則対面です。これまでの経験と今後のキャリアプランを見ます。双方の要望に応じて、社員とのカジュアル面談が設けられる場合もあります。

その最終面接が役員・本部長クラスで原則対面という構成は、事業とキャリアの方向をすり合わせる場に重心があることを示します。

向いている人

チームで動く環境を求める人に向いています。プロジェクトとは別に組織体制ごとのチームがあり、月1回の勉強とナレッジ共有の場、月1回の全社総会があります。所属先が案件だけになりません。

また、SIerやSESで上流を経験し、コンサルティングへ移りたい人にも合います。そのまま活きるのは、要件定義やPM、PL、PMOの経験です。会社自体が開発中心のSIerからDXコンサルティングへ転換してきた経緯を持つため、同じ移行を組織として通ってきています。

さらに、役割を固定せずにキャリアを組みたい人にも向いています。SE、コンサルタント、PM、PMOの間の移動が可能です。8段階の職位ごとに役割と期待値、処遇の基準が社内公開されています。次に何を求められるかが見える状態でキャリアを設計できます。

このほか、AIを実務で扱いたい人にも合います。AI戦略室があり、エージェント開発から戦略立案、機械学習、ガバナンスまでが対象領域です。4段階の研修と社内での継続配信も用意されています。自社向けAIエージェントの開発という、試せる場もあります。

加えて、上場企業のプライム案件で上流から入りたい人にも向いています。エンド・事業会社が商流の37%を占め、案件は数人月から10数人月の少人数体制です。構想策定やRFP策定といった最上流の工程を、数名の中の一人として担えます。

まとめ

METATEAM株式会社は、開発中心のSIerからエンタープライズDX支援へ事業を転換したITコンサルティングファームです。グループ約950名の規模で、上場企業のプライム案件を構想策定から実装まで担います。チームワークを組織運営の軸に置き、8段階の職位ごとに役割と期待値を定義した評価の仕組みと、AI領域の専門組織および段階的な研修が特徴です。2023年9月には東証プライム市場上場のLTSと資本業務提携を締結しました。ステラキャリアズでは、各社の選考傾向を踏まえたご相談を承っています。

※本記事は2026年8月時点で作成しています。制度・人員規模・案件構成などは変更される場合がありますので、最新の情報は公式サイト等をご確認ください。
